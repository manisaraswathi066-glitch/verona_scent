VELOURA — Luxury Perfume Website

Included:
• Black + gold luxury responsive UI
• VELOURA logo and branding
• Split-image marquee showcase
• 8 signature perfume products using the VELOURA bottle artwork
• Category filters
• Add to Cart + cart drawer + subtotal
• Login / Register modal
• Registration fields: Full Name, Phone Number, Email, Address, City, PIN Code, Location, Password
• Current-device location button (browser permission required)
• Account panel + logout
• Newsletter signup demo

Run locally:
1. Extract the ZIP.
2. Open the extracted folder in VS Code.
3. Open index.html with Live Server, or double-click index.html.

Important:
This authentication is a front-end demo using browser localStorage. It is NOT production security. A real store should use a backend database, hashed passwords, server-side sessions/JWT, validation, HTTPS, CSRF protection, rate limiting, and a real payment gateway.
